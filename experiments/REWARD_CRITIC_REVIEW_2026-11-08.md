## 问题与实际结果

158368 步模型在 20.6 秒达到 8.629391 米，展示了值得继续分析的主动近距拦截尝试。但它未进入 5 米捕获范围，之后错过并拉远。“最接近的已保存 MAPPO 确定性轨迹”尚不是任务成功策略。

本轮对各自原 checkpoint 的 Critic 做状态前向计算，没有运行新回合：

| 指标 | 158368 步近距模型 | 1024 步无折扣回报最高模型 |
| --- | ---: | ---: |
| 回合最近距离 | 8.629 m | 20.835 m |
| 终局最近距离 | 204.139 m | 22.936 m |
| CSV 无折扣回报 | -303.110 | -121.906 |
| 原轨迹完整折扣回报 G0，gamma=0.99 | **+9.297** | -5.873 |
| 各自 Critic 初态预测 V(s0) | -23.322 | -2.997 |
| 轨迹 V 与折扣未来回报的描述性相关系数 | 0.988 | 0.752 |
| 描述性 RMSE | 21.080 | 49.494 |

近距模型在第 206 步、20.6 秒：

- P1 距敌机 8.629 米，此前无折扣累计奖励已为 **+145.920**。
- Critic 对该状态的后续收益预测为 **-255.468**。
- 沿实际保存轨迹继续执行，折扣后的未来回报为 **-283.038**。
- 此后未折扣奖励合计为 **-449.030**。

**该处负 Value 有后续失败作为依据。** Critic 预测从当前状态继续执行的未来收益，不是给当前几何距离单独打分。调整的目标应是让策略把接近转化为捕获，并检查奖励是否给这种动作改进提供了恰当信号。

## 解释边界

1. 无折扣总分偏低，不代表训练折扣目标也将这条轨迹排得更低；本例折扣后排序已经反转。
2. 两个 Critic 属于不同训练阶段和策略，不能直接比较它们的 V(s0) 来排序模型。
3. Critic 对应带探索的随机策略及训练时 lambda-return；本轮参照是确定性轨迹的完整 Monte Carlo return。RMSE 与相关性是描述性诊断，不是历史训练 value loss，不能据此证明 Critic 正确或错误。
4. Actor 更新还依赖 Advantage、采样动作和 PPO clipping。抬高奖励绝对数值或手改 Critic 输出，并不自动提供正确的改进方向。
5. 同一环境的静止对照最近距离 **6.732 米**、总回报 **-105.703**，同样失败。因此只奖励全回合最小距离，会把被动等待排在 8.63 米主动尝试之前。
6. 只保留正 active progress、取消远离成本，可能让反复接近/远离刷奖励。只为了让这个 checkpoint 得第一调系数，还会过拟合单条失败轨迹。

## v06 奖励验收提案：尚未实现

当前配置仍是 v05；下一版需要先明确公式，再通过以下检查：

- **安全捕获优先**：无碰撞真实捕获应优于近距失败，不能把 8.63 米包装成完成任务。
- **主动拦截具有价值**：在基地外的有效接近与控制应能区别于被动等敌机靠近；不能只看全回合最小距离。
- **分段信用清楚**：分别分析接近、最近点、错失后和终局分量，以及 Critic/Advantage 的响应。
- **往返不能套利**：构造接近—远离—再接近的路径，不能靠重复正进展刷取收益。
- **尺度可解释**：塑形累计应有清楚的尺度/边界，终局、安全与时间项保留明确权衡，参数放入独立 YAML。
- **统一对照**：检查已存策略、stationary、random 和安全成功案例，同时看捕获、碰撞、未折扣与折扣回报。历史训练成功回合只有回合指标，不能编造其逐步轨迹。
- **离线检查不能代替训练**：旧确定性轨迹不能无校正地当作 PPO on-policy 样本。新训练应作为新 run 单独记录。

本轮未创建 v06 配置、模型或训练结果；具体奖励公式尚待研究决策，不能把这些验收要求描述为已经实施的修复。
